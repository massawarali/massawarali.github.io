Create-BulkADUsers.ps1

PowerShell / AD DS

Automated CSV-driven Active Directory user provisioning script that assigns Organizational Units (OUs), sets secure default passwords, and logs creation status.

Snippet Preview 
Import-Module ActiveDirectory
Import-Csv ".\Users.csv" | ForEach-Object {
  New-ADUser -Name $_.DisplayName `
    -SamAccountName $_.Username `
    -Path $_.TargetOU `
    -AccountPassword (ConvertTo-SecureString $_.Pass -AsPlainText -Force) `
    -Enabled $true
}

PowerShell / SysAdmin

Streamlined workstation onboarding script utilizing Add-Computer -NewName with automatic 15-character NetBIOS length validation and safe reboot handling.

Snippet Preview

  Add-Computer -DomainName "corp.enterprise.local" `
    -NewName $NewHostName `
    -Credential $DomainCred `
    -Restart -Force
